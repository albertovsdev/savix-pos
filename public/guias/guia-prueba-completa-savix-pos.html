SAVIX POS · GUÍA DE PRUEBA OPERATIVA

Una prueba completa, de apertura a reporte.

Recorre un turno corto con una venta de mesa, una compra, inventario, preparación, cobro y revisión de resultados. Usa datos de prueba; no necesitas conocer detalles técnicos.

Empezar la guía
Antes de empezar. Inicia sesión con una cuenta administradora. Si es una instalación nueva, completa primero el asistente inicial con negocio, sucursal y usuario administrador. Para esta práctica usa una sucursal y un producto simple, por ejemplo una bebida.

Ruta rápida del ejercicio

Prueba completa paso a paso

  1. Confirma tu negocio y sucursal

    En el Panel, abre Administración. Revisa Negocio y ticket: nombre comercial, IVA, tema y ancho de ticket. En Sucursales, verifica que exista una sucursal activa, por ejemplo “Matriz”. Guarda solo si cambiaste algo.

  2. Prepara equipo y permisos mínimos

    En Administración → Equipo, confirma que el usuario de prueba tenga sucursal asignada. Para una prueba completa, usa el administrador o asigna permisos de catálogo, operación, preparación, caja, inventario, compras y reportes.

    Si un módulo no aparece en el panel, normalmente es porque falta el permiso o el módulo no está habilitado para esa sucursal.

  3. Crea un área de preparación

    Abre Catálogo → Áreas de preparación. Crea “Cocina” o “Barra”. Esta área recibirá los productos enviados desde una ronda. Si usarás otra cuenta para preparar, asígnale esa área desde Administración.

  4. Registra un producto para vender

    En Catálogo → Productos, crea “Limonada de prueba”. Elige un precio de venta, por ejemplo $45.00. Para practicar inventario, selecciona Por unidad, captura existencia inicial 0 y mínimo 2. Déjalo disponible para la sucursal y envíalo al área “Barra” o “Cocina”.

    Resultado esperado: el producto aparece como disponible en la lista.

  5. Registra un proveedor y una compra

    Abre Compras. Primero crea un proveedor, por ejemplo “Proveedor de prueba”. Después registra una compra: selecciona ese proveedor, el producto “Limonada de prueba”, cantidad 12 y costo unitario $18.00. Guarda la compra.

    Resultado esperado: la compra aparece en “Últimas compras” y la existencia aumenta a 12.

  6. Verifica la entrada en inventario

    Abre Inventario. Busca el producto y confirma que muestra 12 unidades. En “Últimos movimientos” debe aparecer una entrada por compra. No hagas ajustes todavía; esta revisión confirma que la compra afectó existencias.

  7. Abre una mesa y arma una ronda

    En Operación, crea “Mesa 1” si no existe y ábrela. En “Agregar a ronda”, selecciona la limonada, cantidad 2 y una nota opcional, por ejemplo “sin hielo”. Agrega el producto y revisa el borrador.

    Cuando esté correcto, pulsa Confirmar y enviar ronda. La ronda deja de ser editable y pasa al área configurada.

  8. Avanza la preparación

    Abre Preparación y selecciona la sucursal y el área. La limonada debe aparecer como pendiente. Pulsa Iniciar preparación, después Marcar listo y finalmente Entregar.

    Resultado esperado: se reconoce el ciclo completo de cocina o barra y la venta conserva su ronda enviada.

  9. Cobra la cuenta

    Ve a Caja, abre “Mesa 1” y usa la parte general o crea una parte con el nombre “Cliente prueba”. Confirma que los productos estén asignados a la parte. Pulsa Cobrar parte, elige efectivo o tarjeta y captura exactamente $90.00.

    Confirma el cobro. Si es efectivo, registra el importe exacto para esta práctica. Al pagarse todas las partes, la mesa se libera y se genera el ticket de navegador.

  10. Revisa inventario y el reporte

    Regresa a Inventario: la existencia debe quedar en 10 y debe aparecer una salida por venta. Finalmente abre Reportes, usa la fecha de hoy y pulsa Actualizar reporte. Debes ver una venta cerrada, venta total de $90.00, la forma de pago y la compra registrada.

Pruebas rápidas opcionales

Cuenta dividida

Abre otra mesa, agrega dos productos y en Caja crea “Ana” y “Luis”. Asigna un producto a cada parte y cobra cada una por separado.

Cancelación autorizada

Envía un producto a preparación y usa “Cancelar producto enviado” en Operación. Captura motivo y las credenciales del autorizador. Indica si ya fue preparado.

Ajuste de inventario

En Inventario, selecciona un recurso y registra una nueva existencia física con un motivo claro. Revisa el movimiento generado.

Ticket

Tras cerrar una cuenta, abre o imprime el ticket. Confirma que muestra el logo, datos del negocio, impuestos y el formato de 58 u 80 mm configurado.

Acceso desde otra computadora

  1. Prepara la aplicación para compartir

    Primero ejecuta npm run build y deja de usar npm run dev. Después inicia Laravel con C:\xampp\php\php.exe artisan serve --host=0.0.0.0 --port=8000. Así otras computadoras recibirán los archivos compilados desde la misma URL.

  2. Obtén la IP local de esta computadora

    En PowerShell ejecuta ipconfig y localiza la dirección IPv4 de la red Wi-Fi o Ethernet, por ejemplo 192.168.1.25.

  3. Comparte la URL

    Desde otra computadora conectada a la misma red abre http://192.168.1.25:8000. Esta guía queda disponible directamente en http://192.168.1.25:8000/guias/guia-prueba-completa-savix-pos.html.

Importante: comparte solo dentro de una red confiable. Si Windows pregunta por el firewall, permite el acceso únicamente en redes privadas. No abras el puerto a Internet pública.
